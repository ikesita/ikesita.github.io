# 無料計算ツール集

暮らしとお金にまつわる「ちょっと計算したい」に応える、無料のWebツール集の総合案内ページです。会員登録は不要で、入力した内容はブラウザの中だけで処理され、サーバーへ送信されることはありません。各ツールの計算結果は目安であり、正式な金額は公式情報でご確認ください。

## 🌐 ライブサイト

**[https://ikesita.github.io/](https://ikesita.github.io/)**

## ツールサイト一覧

- **無料計算ツール集** — 日本語のツール集。光回線・格安SIMの実質月額比較、FPS感度、消費税・手取りなどの計算ツール：https://ikesita.github.io/free-tools-site/
- **お金の計算ツール集** — ふるさと納税・税金・年金・住宅ローン・手取りの目安：https://ikesita.github.io/money-tools/
- **暦・日付ツール集** — 和暦変換、干支・九星、月齢、誕生日計算、2027年・2028年カレンダー：https://ikesita.github.io/calendar-tools/
- **Free Online Tools & Calculators** — 英語版ツール集。QRコード、BMI、ローン、日付計算など：https://ikesita.github.io/free-tools-en/
- **Health Calculators** — 健康計算ツール集。BMI、体脂肪率、TDEE、ランニングペース、睡眠、出産予定日など：https://ikesita.github.io/health-calculators/

## 使い方

上の一覧から目的のサイトを開き、使いたいツールを選ぶだけです。インストールや会員登録は不要です。

## 注意事項

計算結果はあくまで目安です。正式な金額や条件は、各サービスの公式情報でご確認ください。
